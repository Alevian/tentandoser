VIRTUAL BOX NO DEBIAN

2014-07-22


No último dia 18 de maio, instalei uma maquininha virtual no Debian, para nela colocar coisinhas como Android 4.4, Puppy Linux, Slackware e até outra versão do próprio Debian.

O primeiro passo, claro, foi buscar na internet as instruções.

No link abaixo encontrei o que era necessário:

http://tutorfreebr.blogspot.com.br/2013/11/como-instalar-virtualbox-432-no-debian.html

Fui então visitar minha sources list, seguindo a instrução...

Primeiro problema: Usando o terminal, não consigo acessar o gedit como root!

(gedit:3757): EggSMClient-WARNING **: Failed to connect to the session manager: None of the authentication protocols specified are supported

Solução: entrar pelo terminal de root!
